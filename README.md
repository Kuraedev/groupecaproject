# Digital Twin Career Agent

## About

An AI-powered Digital Twin that represents a professional 24/7. Built with Next.js 16, Vercel AI SDK v6, and Neon Postgres.

**🚀 Live Demo:** https://grouptwodigitaltwin.vercel.app/

## Repository

**📂 GitHub:** https://github.com/Kuraedev/groupecaproject

## Features

- Real-time AI conversations
- Interview simulations
- Profile-based responses
- Persistent conversation history

## Tech Stack

- **Frontend:** Next.js 14+
- **Backend:** Node.js 18+
- **AI Model:** OpenAI GPT-4 / Claude 3.5
- **Database:** Supabase (PostgreSQL)
- **Deployment:** Vercel
